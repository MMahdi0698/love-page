## 🇬🇧 English

A tiny romantic web page I built to ask someone out. 🌹
It's pink, it's full of floating red hearts, and the **"No"** button... well, it gets smaller every time you press it 😏

### ✨ What's inside

- 💬 A sweet question with two buttons, and a "No" button that never wins
- 📅 **"Which date is this?"**: first 😄, second 😊, third 😎 or fourth 😘
- 🍕 **"Where should we eat?"**: fast food 🍕, restaurant 🍗, café ☕ or in the car 🚘
- 💖 Glassy cards, floating hearts, a sparkly star trail that follows your mouse or finger, and tiny click animations
- 📱 Works on phones, tablets and desktops

### 🛠️ How it works

- The page is plain **HTML, CSS and JavaScript**, hosted for free on **GitHub Pages**. No server needed. 😎
- Answers go to a tiny **Cloudflare Worker**, which saves each one as a small file in a **private** GitHub repository, so only I can see them. 🔒
- What gets saved: your choices, the time, an optional name taken from the link, and basic info like country and browser. Nothing more.
